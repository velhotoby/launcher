COBBLEMON LEGACY LAUNCHER - INSTALADOR ONLINE
==============================================

Este pacote inclui o Java 21 necessário para executar o launcher.
O instalador 2.0 trabalha diretamente na pasta do usuário e não executa
componentes próprios no diretório temporário do Windows, evitando o fluxo
que provocava o erro 4551 do Controle de Aplicativos.

Durante cada instalação, a release estável mais recente é baixada diretamente
do GitHub e validada por SHA-256. Uma cópia segura incorporada fica disponível
como contingência quando não há conexão.

O Minecraft não é redistribuído: seus arquivos são obtidos dos serviços oficiais
quando o usuário inicia o jogo e autentica sua própria conta.

Recursos:
- Minecraft 1.21.1 e Fabric 0.19.5
- Cobblemon 1.8.1 e sincronização segura dos mods
- perfil local e autenticação Microsoft
- idioma Português (Brasil) e atalhos padrão
- três endereços do servidor Cobblemon Legacy configurados
- atalhos criados na Área de Trabalho, menu Iniciar e barra de tarefas

Dados do jogo:
%USERPROFILE%\.cobblemon_legacy

Dados internos do launcher:
%USERPROFILE%\.cobblemon_legacy_launcher

Log do instalador:
%USERPROFILE%\.cobblemon_legacy_launcher\logs\windows-installer.log
